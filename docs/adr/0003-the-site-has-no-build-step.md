# The site has no build step

- **Status:** accepted
- **Date:** 2026-11-14
- **Related:** ADR-0001, README (*Editor workflow*, *The Programma*,
  *Tests*, *Deployment*), `tests/site.test.mjs`

The site ships as the files it is: `index.html`, `assets/css/style.css`,
`assets/` at the repository root, served as they are written. Eleventy, the
`src/` tree, the data file, the includes and the `_site/` output are gone. This
records what that cost, because the previous arrangement was not accidental — a
front-matter content model, Italian dates generated by `Intl`, a layout that made
it impossible for an editor to break the markup, and a test that proved all
three.

What was given up, and where each guarantee went:

- **The content model.** There was one entry and one page; the page still is one
  file and one page, and the assertion that the printed facts appear on it is the
  test that already covered it.
- **Generated dates.** The five date strings are now literals. A test recomputes
  the weekday, day number, month and year from `datetime="2026-12-06"` with
  `Intl` and fails on drift, so the date cannot disagree with itself.
- **An editor cannot break the layout.** This is no longer true. The prose sits
  in a marked region and the signature path is reflowed across lines so the file
  is navigable, but the Comitato edits HTML now, and a bad edit can break the
  page. The trade was accepted for a site that needs no toolchain to exist.
- **The front-matter test.** Deleted: it edited a build input to prove a build
  output changed, and there is neither. In its place, a test that the shipped
  HTML carries no unrendered template syntax and that `index.html` is the only
  page.

Deployment keeps the Actions pipeline from ADR-0001 but splits it: one job
installs Node and runs the tests, a second checks out and uploads the root
without installing anything — otherwise `node_modules/` would be published.
Node survives in the repository only as the test runner.

## Considered options

- **Keep Eleventy and rename the entry to `.html`.** Removes Markdown and none
  of the build.
- **No build, but concatenate `partials/signature.html` at deploy.** Keeps the
  editable file small; reintroduces a build step to do it.
