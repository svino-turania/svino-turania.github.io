# Search submissions

The page is optimised for the brand query and for local intent. What actually
makes a new site appear under "eventi Turania" is being listed where those
searches already land. Each listing below is a citation and a link; most are
free. Send them from the Comitato's own address, so the listing names the
organiser, not the maintainer.

Use only the approved facts. Do not add an end time, a price, an entry policy
or a number of cantine: the page does not publish them and the Comitato has not
decided them. Do not claim that sVino is part of *Cantine Aperte a Natale*: it
falls on the same day but is a separate event.

## Search Console

The property is verified by the `google-site-verification` meta tag in
`index.html`.

1. Deploy `main` first, so the sitemap's `lastmod` and the `Event` block are
   live.
2. Search Console → Sitemaps → submit `sitemap.xml`.
3. Search Console → URL inspection → `https://svino-turania.github.io/` →
   Request indexing.
4. After 48–72 hours, check that the page is indexed. After two weeks, open
   Performance and filter for the target queries below.

Bing Webmaster Tools is optional; submitting the sitemap there is enough.

## What to measure

Target queries, in order of expected winnability:

1. `svino turania`
2. `sVino Turania 6 dicembre`
3. `festa del vino Turania`
4. `eventi Turania dicembre 2026`
5. `cantine Turania`
6. `cosa fare a Turania`

Success for this edition is: the page indexed, the listing live on at least
three aggregators, and impressions for queries 1–3. It is not page-one
placement for `eventi Lazio`: that belongs to the regional calendars, which is
why being listed on them is the point.
